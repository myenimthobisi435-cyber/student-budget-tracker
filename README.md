# Student Budget Tracker 
A python app to help students track expenses and stay within budget.

## What it does
- Add an expense with name, amount, and date
- View all expenses, tatal spent, and budget left
- Delete an expense
- Saves data in expenses.json, works offline

## How to run
python budget.py

## Built with
Python, JSON, datetime
